- Added property selection functionality to property enquiries.
- Added dynamic property details functionality using URL parameters.
- Added property search and filtering functionality.
- Added responsive mobile navigation functionality.
- Added `robots.txt`.
- Added `sitemap.xml`.
- Added SEO-focused page titles and meta descriptions.
- Added descriptive image `alt` attributes.
- Added and reviewed internal links between website pages.

- Improved form field error handling and validation feedback.
- Improved navigation and internal page linking.
- Improved SEO structure through descriptive titles, meta descriptions and heading hierarchy.
- Reviewed website pages for H1, H2 and H3 structure.
- Reviewed website images for accessibility and SEO.
- Reviewed internal links throughout the website.
